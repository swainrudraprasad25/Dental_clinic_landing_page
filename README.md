# 🦷 Dental Clinic Landing Page

A responsive, front-end landing page for a dental clinic, built with HTML and CSS.

## ✨ Features
- Hero section with clinic name, addresses, phone numbers, and a **Book Online** button
- Services section: Dental Care, Oral Surgery, Dental Bridges, Teeth Cleaning
- "Our Team" section with six doctor profile cards
- Icons from Font Awesome

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- Font Awesome (CDN)

## 📁 Project Structure
```
Dental_clinic_landing_page/
├── index.html
├── style.css
└── *.jpg        # hero image
```

## 🚀 Run Locally
```bash
git clone https://github.com/swainrudraprasad25/Dental_clinic_landing_page.git
cd Dental_clinic_landing_page
```
Then open `index.html` in your browser.
